## 00 / SYSTEM OVERVIEW

I’m an Electronics and Telecommunication Engineering student focused on **digital hardware, embedded computing, and intelligent edge systems**. My interests center on how algorithms become real implementations: arithmetic architecture, RTL control and verification, sensor-to-telemetry pipelines, and signal-processing workflows.

<div align="center">

```text
  INPUT / SPECIFICATION
          │
          ▼
  MODEL ──► ARCHITECT ──► IMPLEMENT
                            │
                            ▼
  MEASURE ◄── OPTIMIZE ◄── VERIFY
```

</div>

| Domain | Current technical focus |
|:--|:--|
| **Digital design** | Verilog/SystemVerilog, RTL structure, datapath/control separation |
| **Hardware acceleration** | Fixed-point arithmetic, MAC/ReLU datapaths, CNN accelerator foundations |
| **Embedded systems** | C/C++, STM32, sensor interfacing, MQTT telemetry |
| **Signal processing** | MATLAB, FFT, vibration analysis, condition monitoring |
| **Engineering computation** | Python, geometry, tolerance analysis, numerical modeling |
