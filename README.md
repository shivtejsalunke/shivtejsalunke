## About

I'm an Electronics and Telecommunication Engineering student interested in efficient hardware systems for computationally demanding applications.

My focus is on FPGA-based acceleration, RTL design, Edge AI, embedded firmware, and digital signal processing. I enjoy exploring how algorithms translate into practical hardware-software implementations—from fixed-point datapaths and embedded sensing to signal-analysis pipelines.

- **Primary focus:** FPGA, SystemVerilog, RTL design
- **Exploring:** Hardware acceleration and Edge AI
- **Embedded:** C/C++, STM32, sensor interfacing, MQTT
- **Signal processing:** MATLAB, FFT, condition monitoring
- **Engineering tools:** Vivado, KiCad, Python

> Understand the algorithm. Design the implementation. Verify the result. Measure the trade-offs.
